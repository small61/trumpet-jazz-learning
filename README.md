# 小号爵士学习

这是一个个人学习仓库，用于记录从重新拿起小号，到能够演奏爵士标准曲并进行基础即兴的过程。

## 我的起点

- 约 5 年前学过小号，具备基础吹奏经验
- 使用 Yamaha YTR-2330
- 目前需要重新建立稳定的气息、音色、耐力和音准
- 长期目标是爵士演奏与即兴，参考 Davide Severino 的演奏表达与爵士语感

## 学习路径

1. 恢复基本功：呼吸、长音、连音、吐音与稳定音色
2. 熟悉调性：大调音阶、和弦分解与节拍器练习
3. 学会读谱：理解 Real Book、和弦符号和曲式
4. 积累语言：听唱、模仿、转录短句和 ii–V–I
5. 进入即兴：先限制音符，再逐步连接和弦与乐句

## 使用方式

每次练习前选择一个明确目标，结束后在日志中记录实际完成内容、遇到的问题和下一步。每月复盘一次录音，以音色、节奏、音准、耐力和爵士语言五项作为观察维度。
